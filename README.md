# Hand Pen 🍌

A fun hand-detection drawing project using your webcam.

## How to use it

1. Allow camera access.
2. Hold the **SHIFT** key on your keyboard to start drawing ink.
3. Release **SHIFT** to move your hand to the next letter.
4. Press the **SPACEBAR** if you make a mistake and want to clear the screen.

Feel free to experiment with the colors and smoothing.
